Возможности

Всё для игры — в одном окне

Lylos Launcher объединяет управление сборками, установку контента, настройки запуска и релизные версии приложения для Windows.

I

Управление сборками

Создание отдельных Minecraft-сборок с собственной версией игры, loader, RAM, Java и папками.

M

Каталог Modrinth

Поиск и установка модов, модпаков, шейдеров и ресурспаков из каталога Modrinth.

A

Аккаунты Ely.by

Вход через Ely.by OAuth (PKCE), обновление токена перед запуском и authlib-injector для скина в игре.

T

Темы интерфейса

Несколько полноэкранных тем оформления: LL тёмная, AMOLED, глубокий фиолет, океан, эндер и закат.

R

Автообновление

Лаунчер сам проверяет новую версию и предлагает обновиться — без ручной переустановки.

О проекте

Открытый код, честные обновления

Lylos Launcher — полностью open-source проект на Python и PySide6. Исходники открыты, релизы собираются автоматически, а версия для обновления публикуется в realese.json на GitHub Pages.

FAQ

Частые вопросы

Как установить Lylos Launcher?

Скачай Windows installer и запусти его — установка займёт пару минут. Или используй Portable ZIP: распакуй и запусти LylosLauncher.exe.

Нужна ли Java?

Нет. Лаунчер сам скачает подходящую версию Java (Temurin JRE) под выбранную сборку Minecraft.

Как добавить мод или мир из архива?

В карточке сборки нажми «+ Добавить мод» или «+ Добавить мир» и выбери ZIP/JAR. Лаунчер сам распакует файлы в нужные папки.

Как лаунчер обновляется?

При запуске Lylos Launcher проверяет realese.json на сайте проекта. Если вышла новая версия — скачает installer и предложит обновиться.
