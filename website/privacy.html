Конфиденциальность

SMLauncher хранит основные настройки, сборки и логи локально на компьютере пользователя.

Локальные данные Сборки, настройки, логи и выбранные параметры запуска сохраняются на устройстве пользователя.
Внешние сервисы Каталог использует Modrinth, а сайт получает информацию о релизах через GitHub Releases.
Авторизация Ely.by Данные аккаунта Ely.by обрабатываются только локально и не передаются третьим лицам.
