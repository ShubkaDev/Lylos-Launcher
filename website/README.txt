Lylos Launcher website

Статический сайт проекта на GitHub Pages. Контент описывает функции лаунчера:
- загрузка Windows installer и portable ZIP (данные берутся из release.json / realese.json);
- управление сборками;
- каталог Modrinth;
- моды, шейдеры, ресурспаки и модпаки;
- аккаунты Ely.by;
- автообновление через realese.json.

realese.json — источник версий для автообновления лаунчера.
